PSOAP-modernized
================

Precision Spectroscopic Orbits A-Parametrically ("PSOAP") is a package for
modelling time-series stellar spectroscopy with Gaussian processes, jointly
fitting orbital motion and component spectra.

Project repository: `piotrlojko/PSOAP-modernized <https://github.com/piotrlojko/PSOAP-modernized>`_

Supported operational models in this codebase are:

* ``SB2`` — double-lined spectroscopic binary
* ``ST2`` — hierarchical triple with two visible components
* ``ST3`` — hierarchical triple with three visible components
