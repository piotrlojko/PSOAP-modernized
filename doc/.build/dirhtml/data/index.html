Data¶

PSOAP loads per-epoch spectra from plain-text files through psoap.data.

Expected input format¶

A run is defined by spectra_list (set in config.yaml), containing two columns:

  • filename: path to spectrum text file

  • date: observation date (JD)

Each spectrum file must have 3 columns:

  1. wavelength [Angstrom]

  2. normalized flux

  3. sigma

Data handling details¶

psoap.data.Chunk is the core container. Chunk.from_textfiles:

  • reads all epochs

  • interpolates onto a common wavelength grid (from first epoch)

  • supports optional wl_min / wl_max clipping

  • stores arrays for wavelength, flux, sigma, and epoch dates

Masking is applied with psoap.data.Chunk.apply_mask() before likelihood calls.

API reference¶

class psoap.data.Chunk(wl, fl, sigma, date, mask=None)[source]¶

Hold a chunk of spectral data. Each chunk is shape (n_epochs, n_pix) and has components wl, fl, sigma, date, and mask.

Input spectra are expected as normalized 1D spectra: wavelength in Angstroms, normalized flux (continuum at 1) in arbitrary units, and flux error.

classmethod from_textfiles(filenames, dates, limit=None, wl_min=None, wl_max=None)[source]¶

Load spectra from plain-text files with three columns: wavelength (Angstroms), normalized flux, and flux error.

Parameters:

  • filenames (list of str) – paths to the text files, one per epoch.

  • dates (array-like) – observation dates (JD) for each epoch.

  • limit (int, optional) – maximum number of epochs to load.

  • wl_min (float, optional) – minimum wavelength to include [Angstroms].

  • wl_max (float, optional) – maximum wavelength to include [Angstroms].

Notes

When a spectrum’s wavelength range does not fully cover wl_min– wl_max, interpolation is performed with fill_value=1.0 for flux (appropriate for normalized continuum spectra) and fill_value=np.inf for sigma (effectively masking those pixels during GP evaluation).

Returns:

the instantiated Chunk object.

Chunk

psoap.data.replicate_wls(lwls, velocities, mask)[source]¶

Using the set of velocities calculated from an orbit, copy and blue-shift the input ln(wavelengths), so that they correspond to the rest-frame wavelengths of the individual components. This routine is primarily for producing replicated ln-wavelength vectors ready to feed to the GP routines.

Parameters:

  • lwls (1D np.array with length n_good_pixels) – the 1D representation of the natural log of the (masked) input wavelength vectors.

  • velocities (2D np.array with shape (n_components, n_epochs)) – a set of velocities determined from an orbital model.

  • mask – the np.bool mask used to select the good datapoints. It is necessary for properly replicating the velocities to the right epoch.

Returns:

A 2D (n_components, n_good_pix) array of the wavelength

vectors blue-shifted according to the velocities.

Return type:

np.array
